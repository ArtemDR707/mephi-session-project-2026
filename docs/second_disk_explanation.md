# Что значит второй диск `/dev/sdb`

В задании требуется подключить второй диск `/dev/sdb`.

Это не раздел на основном диске, а отдельный виртуальный диск в настройках виртуальной машины.

Проверка:

```bash
lsblk
```

Корректный вариант до выполнения задания может выглядеть так:

```text
NAME   MAJ:MIN RM  SIZE RO TYPE MOUNTPOINTS
sda      8:0    0   20G  0 disk
├─sda1   8:1    0    1G  0 part /boot
└─sda2   8:2    0   19G  0 part /
sdb      8:16   0   10G  0 disk
```

Именно `sdb` будет размечен в один раздел `sdb1`, отформатирован как ext4 и примонтирован в `/data/mephi-web`.

После настройки ожидаемый вид:

```text
sdb      8:16   0   10G  0 disk
└─sdb1   8:17   0   10G  0 part /data/mephi-web
```
