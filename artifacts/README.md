# Артефакты

Эта папка оставлена для промежуточных файлов.

По требованиям задания итоговые артефакты лучше держать в корне репозитория:

- `project_history.txt`
- `network_check.txt`
- `nginx_recent_logs.txt`
- `fstab.txt`
- `selinux_status.txt`
- `file_contexts.txt`
- `tcpdump_capabilities.txt`
- `permissions.txt`
- `users_groups.txt`
- `index.html`
- `curl_output.txt`
- `mephi-nginx-screenshot.png`
- `tcpdump.rpm`

Файлы должны быть получены после реального запуска команд на Fedora 43.
